Variables and data types — Detailed Explanation

A variable is a name referring to a value; assignment uses =. Common types are int (whole number), float (decimal), str (text), bool (True/False), and NoneType (no value). Use type(x) to inspect a value. Names should start with a letter or underscore, must not start with a digit, and must not be Python keywords. snake_case such as student_name is a readable convention.

Example and practice

Examples: age = 15; price = 2.5; name = "Aye"; active = True. Convert with int("12"), float("3.5"), or str(25); invalid text may raise ValueError.

Conditional statements — Detailed Explanation

if executes a block when its condition is true. elif checks another condition if previous conditions were false. else handles the remaining cases. Indentation determines which lines belong to each branch. Check specific conditions before general ones, especially when score ranges overlap. Test boundary values to catch mistakes.

Loops — Detailed Explanation

A for loop iterates over a sequence or range. A while loop repeats while its condition is true. range(start, stop, step) excludes stop. break exits the nearest loop; continue skips the rest of the current iteration. A while loop needs an update that eventually makes its condition false, otherwise it may run forever.

Example and practice

Example: for n in range(1, 4): print(n) displays 1, 2, 3. Trace the counter in a while loop and identify exactly when it stops.

Check your understanding: Explain the concept in your own words and create one example without copying.

for loop သည် sequence သို့မဟုတ် range ကို အစဉ်လိုက် လုပ်ဆောင်သည်။ while loop သည် condition မှန်နေသရွေ့ ထပ်လုပ်သည်။ range(start, stop, step) တွင် stop ကို မထည့်ပါ။ break သည် လက်ရှိ loop မှ ထွက်ပြီး continue သည် လက်ရှိအကြိမ်၏ ကျန် code ကို ကျော်သည်။ while loop တွင် condition false ဖြစ်လာစေမည့် update မရှိပါက အဆုံးမရှိ လည်ပတ်နိုင်သည်။

Program 19: Check Armstrong Number

    digit = temp_num % 10

else:

  • str(num) and len(...) determine how many digits the number contains.
  • temp_num % 10 extracts the last digit. Integer division // 10 removes that digit for the next loop.
  • Each digit is raised to num_digits and added to sum_of_powers. Finally, compare the sum with the original number.
  • For example, 153 = 1³ + 5³ + 3³ = 153. The original number is preserved in num while temp_num is reduced.

Worked example: 153 → 1³ + 5³ + 3³ = 153

Expected result: Output: 153 is an Armstrong number.
